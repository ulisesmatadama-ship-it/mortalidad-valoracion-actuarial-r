# Autoría y reutilización

Este portafolio reconoce el trabajo en equipo y distingue la entrega académica
de las adaptaciones técnicas para mostrarla. No se concede una licencia general
sobre los materiales colectivos ni sobre datos de terceros. Antes de reutilizar
esos materiales, revisar los créditos y las condiciones de su fuente.

La configuración de GitHub Actions usa `actions/checkout` y `r-lib/actions/setup-r`,
bajo sus respectivas licencias. La versión de R fijada para verificación es 4.5.1.
